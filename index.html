Jenkins CI/CD Pipeline

A complete DevOps project demonstrating continuous integration, Docker image creation, and automated pipeline execution using Jenkins, GitHub, Docker, and AWS EC2.

View Pipeline Check Deployment

Project Overview

This project demonstrates a simple CI/CD workflow where the application source code is stored in GitHub and processed through a Jenkins Pipeline to build a Docker image.

Source Code

Application files and pipeline configuration are stored and managed using Git and GitHub.

Automation

Jenkins automatically executes the pipeline stages defined inside the Jenkinsfile.

Containerization

Docker packages the application into a container image using the provided Dockerfile.

CI/CD Pipeline Flow

The Jenkins Pipeline executes the following stages sequentially.

1. Checkout
→
2. Build
→
3. Test
→
4. Docker Build

Technologies Used

The following technologies were used to build and deploy this project.

GitHub

Source code repository and version control.

Jenkins

Continuous Integration and pipeline automation.

Docker

Application containerization and image creation.

Nginx

Web server used to serve the application.

AWS EC2

Cloud infrastructure used to host Jenkins and Docker.
